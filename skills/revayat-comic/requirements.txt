# Python 3.10 or newer. The scripts use `X | Y` type unions throughout, which
# is a syntax error before 3.10 — on 3.9 you get a traceback from the import,
# not a helpful message. CI tests the oldest and newest supported interpreters.
#
# Note for whoever reads this after 2026-10-04: 3.10 reaches end of life on that
# date and stops receiving security fixes. It is kept as the floor for now
# because dropping it would strand users on a system Python; raising the floor
# to 3.11 is a one-line change here and in the CI matrix.

# Core — required for every run.
pillow>=10.0                  # page IO, and the Persian text renderer
numpy>=1.24                   # every pixel measurement
opencv-python-headless>=4.8   # balloon detection, masks, inpainting

# Strongly recommended. Without it CBZ, CBR and folders still work, but PDF
# input and PDF export do not.
pymupdf>=1.24

# Persian shaping fallback. Pillow wheels normally ship RAQM, which does this
# properly through HarfBuzz and FriBidi; these two are only used when it does
# not, and `doctor` says which path is in effect.
arabic-reshaper>=3.0
python-bidi>=0.4

# The hosted adapters in scripts/adapters.py need NO package at all — they are
# plain urllib against any OpenAI-compatible endpoint. Point REVAYAT_API_BASE
# somewhere and set the matching model variable; see README.

# Optional, not installed by default:
#   rarfile>=4.0      CBR archives (also needs an unrar/bsdtar binary on PATH)
#   manga-ocr>=0.1.8  a second opinion on Japanese text (~400 MB of model,
#                     and it pulls in torch — see references/ocr.md before
#                     deciding you need it)

# Development only.
pytest>=8.0
pytest-timeout>=2.3
ruff>=0.16                    # the lint gate in CI; see ruff.toml for the rules
