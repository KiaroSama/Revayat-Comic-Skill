# Manga sound effects in Persian

Read the panel before choosing a Persian equivalent. Look for the object or person making the sound, the size and placement of the lettering, and whether it marks one beat or a repeated action. Some manga effects mark a motion, feeling, or silence and make no literal sound. English labels below are search cues, not fixed translations of the Japanese.

## Verify an unfamiliar effect

1. Read the actual lettering. Keep small kana, repetition, and long-vowel marks in your transcription. Search the web for the Japanese spelling or romanization and `manga SFX`; for English lettering, search the exact word with the depicted action.
2. Compare the results with the panel. [The JADED Network Japanese SFX Dictionary](https://thejadednetwork.com/sfx/) is a starting point for Japanese variants; check the licensed edition or another example if several readings fit. Do not upload a private page or crop to identify one word.
3. Record the verified source spelling, sense, Persian form, and source URL in `$WORK/glossary.json`. Lock verified recurring forms in `comic.json` under `glossary.entries` using the chapter's glossary workflow. Distinguish recurring senses when the same lettering does different jobs. This glossary takes precedence over the short examples in the sound-effects policy guide.
4. If the lettering is still unclear, note the uncertainty and keep the original art. A guessed replacement is hard to undo after cleaning.
