## R01 - Open-balloon speckle sweeping erases distant panel art

**Reproduction and impact.** A 160 by 140 page has a declared panel
`[20,20,120,100]`, source box `[36,46,20,20]`, a source glyph at x42..48/y52..58
and a separate four-by-four artwork detail at x79..83/y99..103. Paper luminance
is 245 and ink is 20. The panel-clipped component is an accepted open balloon.
The local text mask is confined, but the subsequent speckle sweep uses the entire
connected paper component. Pixel `(80,100)` changes from 20 to 245 and its clean
mask becomes 255, despite lying outside the source window. The verified
published v2.0.4 binary reports strict QA success and exports the damaged CBZ.

**Repair.** `masks::open_balloon_cleanup_window` and `OPEN_BALLOON_PAD` define
one source-centered window for open cleanup. The cleaner clips speckle
authorization to that window while retaining the original interior bounds for
the existing balloon-scale speckle-size limit. Closed balloons keep their
full-interior cleaning behavior; kept/dropped exclusions and outlines remain
protected. Cropping the interior bounds instead would change the speckle-size
limit and was rejected by the faint-source control.

**Complete QA closure.** Preserved distant art must not become a false residual
ink failure. `qachecks::balloon_cleanup_interior` applies the same open source
window and inset as cleaning. Both the library residual counter and CLI
exclusion-aware recount use it. Lettering/outline checks retain
`balloon_text_interior`. A control deliberately leaves ink elsewhere in a
closed balloon and still requires a residual finding; QA is not globally
weakened to make preservation pass.

**Acceptance.** Both polarities, normal/bubbles-only cleanup, erased and
translated publication, exact preservation outside the source window, kept
numeric art, closed-balloon full cleaning and exclusions are exercised. Public
CLI tests run import, mask, clean, optional typeset, strict QA and CBZ export.

## R02 - Solid local masks are incorrectly reported as NoInk

**Reproduction and impact.** A fully bounded two-by-two source containing three
ink pixels becomes a solid four-by-four local mask after growth. Dense source
stripes reproduce the same condition. The old `all(pixel != 0)` shortcut treats
that nonempty mask as `NoInk`, leaving the source untouched. The actual published
binary records `fill=no_ink`, passes strict QA and exports the uncleared source.

**Repair.** Remove the shortcut. Existing `clean_region` refuses a solid mask
when no approved repair is available. Add the backward-compatible
`clean_page_bubbles_with_external` entry point; existing wrappers delegate with
no external image. Validate repair dimensions before processing and supply
external pixels only for solid local masks. Existing compositing confines them
to the local authorization. Empty or completely excluded masks remain valid
`NoInk` results.

Wire the supplied external page into CLI balloon cleanup. Allow
`clean --bubbles-only --external-dir ...` by removing the contradictory argument
restriction and documenting its meaning. Bubbles-only mode still skips on-art
processing. Do not automatically manufacture an external repair or accept a
different image geometry.

**Acceptance and recovery.** A two-page CLI fixture first obtains a real CBZ,
then makes the second page require a repair. Refusal leaves the document and
previous CBZ bytes unchanged. Supplying approved native-size repairs removes
the source, preserves every unmasked pixel and distant art, passes strict QA and
replaces the CBZ successfully. Both polarities and both CLI modes are covered.
Separate controls reject wrong geometry and preserve fully excluded source.

The existing `clean --external-dir` contract requires `<page_id>.png` for every
document page, including pages without the difficult region. The repair does
not silently change that contract to a sparse directory. Rebuild mask, clean,
and typeset when applicable, then strict QA and export. Preserve the original
and accepted translation; never remove evidence or widen authorization to evade
a refusal.

## R03 - Larger faint balloon source remains after cleanup

**Reproduction and impact.** A 20 by 20 glyph at luminance 200 on 245 paper,
inside a complete 30 by 30 source anchor, produces an empty local mask under
the fixed balloon threshold of 175. Its 400-pixel component exceeds the small
speckle fallback. Baseline output remains 200 with mask zero and `NoInk`; the
inverted case remains 55. Both the public mask/clean API and actual CLI reproduce
this on unchanged baseline production.

**Repair.** Estimate Otsu statistics from permitted interior pixels, excluding
contour and surrounding art. Clamp balloon thresholds to 175..210, retaining
the existing dark-ink floor and supported faint-text ceiling. The free-text
threshold cap and paper-aware artwork component guard remain unchanged.

**Acceptance.** Test 200-on-245 and 180-on-190 source/paper pairs in both
polarities, including actual source removal and outside-mask preservation.
Public CLI tests cover both erased and translated final publication while
preserving the distant artwork detail. Small faint-source controls remain
active, so the repair cannot rely only on large-component behavior.

## R04 - Otsu arithmetic overflows on supported large pages

**Reproduction and cause.** The real `masks::region_mask` API panics on a
6000 by 3000 constant-245 RGB image, below the supported 80-million-pixel limit.
Pinned imageproc 0.27.0 calculates `(t as u32 * h) as f64`, overflowing before
conversion. Debug overflow is directly reproduced. Release wrapping follows
from that arithmetic; a release crash or a particular incorrect output is not
claimed without a corresponding measurement. The public `detect_page` API also
panics on the same constant page under default options; its unchanged-baseline
reproduction failed at the same upstream multiplication.

**Repair.** Share an allocation-light 256-bin Otsu helper with u64 histogram
counts and f64 weighted sums/variance, converting before multiplication. Use it
for free masks, permitted balloon masks and free-text detection. Preserve the
detector's uncapped threshold semantics, the masks' separate bounds, and the
earliest-threshold tie rule. No dependency upgrade or unsafe code is needed.

**Acceptance.** Empty, constant, bimodal and tied histograms have explicit
controls. Allocation-light counts exercise the 18-million and 80-million-pixel
ranges. A nonignored 18-million-pixel regression exercises both public mask and
detection APIs, sequentially reusing the same image and dropping the mask before
detection. The measured combined run passed in 18.301 seconds with 371,348 KiB
peak RSS. No runtime caller of the overflowing upstream function remains.
