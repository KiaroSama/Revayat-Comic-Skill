# Pure-Rust v2.0.0 Architecture & Migration Decisions

- **Toolchain:** Rust `1.100.0` (`edition = "2024"`, `#![forbid(unsafe_code)]`), single root `Cargo.toml` workspace with 14 crates and a single root `Cargo.lock` (zero PyO3, zero Python).
- **Build & release matrix:** 4 64-bit targets only (`x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu`, `x86_64-pc-windows-msvc`, `aarch64-pc-windows-msvc`). 32-bit and macOS are excluded by default.
- **PDF stack:** Pure Rust (`lopdf` + `pdf-writer` + `hayro`) with R01 stencil-mask and Form XObject pixel-budget checks prior to raster allocation, replacing PyMuPDF.
- **Archive & review formats:** Pure Rust CBR (`rars`), CBZ (`zip`), and Persian RTL DOCX (`quick-xml`).
- **Persian shaping & typesetting:** Pure Rust `cosmic-text` with HarfRust shaping, unicode-bidi analysis, and Swash rasterization, using bundled Vazir TTF fonts (`Regular`, `Medium`, `Bold`), `>= 1.38x` line spacing, zero-dot interior bubble sweep, and non-overlapping text guards. The upstream [0.19.0 README](https://docs.rs/crate/cosmic-text/0.19.0/source/README.md) and [dependency manifest](https://docs.rs/crate/cosmic-text/0.19.0/source/Cargo.toml) document the text stack.
- **TLS/HTTP note:** Optional hosted OCR/translation (`ureq 3.5` + `rustls`) keeps production TLS verification (`ring` transitive crypto); offline comic translation requires no network calls.
- **`rust-anything` migration disposition:**
  - `rust-anything` isolated parity gates passed 237/237 recorded cases (`languages` 23/23, `textmatch` 189/189, `wire` 25/25) plus the nine `*core-rs` kernels.
  - Whole-app legacy `app_replay` matched 1/10 recorded legacy Python CLI transcripts because v2.0.0 intentionally changes `doctor --json` (exits 0 with pure-Rust kernel status rather than exit 1 on missing Pillow/RAQM), uses Rust CLI error diagnostics, and writes UTF-8 UTC run logs rather than Python tracebacks.
  - Native end-to-end verification in `revayat-comic-cli` exercises the complete synthetic CBZ -> detect -> mask -> crops -> worksheet -> glossary -> falint -> clean -> fullpage-prompt -> typeset -> strict QA -> CBZ/PDF/DOCX -> package QA pipeline plus MCP stdio and concurrent loopback HTTP servers.
- **External lettering safety:** `typeset --external-dir` composites only within authorized masks and marks outputs `unreliable` until visually reviewed; full-page image edits use the bubbles-emptied + full-page workflow (`skills/revayat-comic/references/fullpage-image-edit.md`).
- **Publication evidence:** QA and export share the IR publication gate. Derived pages require current clean/typeset evidence, relevant upstream stages must be fresh, and shortened text requires a review bound to its full/displayed pair. Export history itself does not block a new export, and untouched original pages need no rendering stamps.
