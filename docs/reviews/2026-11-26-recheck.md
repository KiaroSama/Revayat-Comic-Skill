## R01 — Free-text masks lose supported contrast ranges

**Impact:** source lettering can remain after an apparently successful mask and
clean operation. A luminance-200 glyph on paper245 and a luminance-20 glyph on
paper160 both produce an empty mask in v2.0.1. Their inverted-polarity variants
exercise the same oriented-luminance contract.

**Cause:** the new Otsu cap179 excludes faint ink, while the fixed `<180` artwork
component guard joins midgray paper to the frame and rejects the enclosed glyph.
The two thresholds do not describe the same ink/paper partition.

**Repair:** in `revayat-vision/src/masks.rs`, restore the supported Otsu cap210 and
derive the component guard from the detected ink threshold and median upper-class
paper luminance. Keep the guard below paper, include all detected ink shades,
and use the same guard after circular dilation. Preserve the rejection of artwork
components extending beyond the source anchor.

**Closure:** tests require nonempty ink authorization, actual source-ink removal,
both polarities, exact preservation outside the mask and an artwork stroke that
crosses the text anchor. Public CLI cases exercise import → mask → clean → strict
QA → ordinary CBZ export for all four contrast/polarity combinations. This tests
erasure, not a claim that every background supports local Persian typesetting.

## R02 — Saved balloon windows bypass fresh-component limits

**Impact:** a stored full-panel search rectangle can promote a large panel paper
component to a balloon, authorizing cleaning beyond the intended text enclosure.
The reproduced component is 182×162 pixels inside a 190×170 panel.

**Cause:** the saved-window fast path only requires a nonempty inset. The fresh
path additionally validates minimum dimensions, source-anchor overlap and the
80%-panel-coverage ceiling.

**Repair:** factor the component acceptance into `resolved_paper_bounds` and call
it from both paths before accepting the interior. Retain the existing cached
luminance/interior reuse and circular dilation implementation.

**Closure:** the identical live page must be rejected as a balloon with and
without the saved full-panel window. Existing valid balloon, narrow-tail,
curved-outline, hair and panel-clip controls remain active. An independent
small-grid Euclidean-disc oracle passed 4,942 cases; no speculative kernel
rewrite is included.

## R03 — Current preservation masks are absent from stage evidence

**Impact:** changing `clean_mask` or `authorized_mask` bytes, swapping their
paths, deleting paths or omitting current proof digests can leave publication
certified. Those files define which changed pixels QA permits, so image hashes
alone cannot establish the same preservation claim.

**Repair:** the CLI writes and hashes `clean_mask` into the cleaning record and
`authorized_mask` into the delivery record. `revayat-ir/src/certify.rs` requires
a valid path and matching digest whenever either the current page path or the
corresponding record key exists. Missing, null, malformed and changed proofs
produce `delivery-mismatch` with a rebuild action. Genuine older records with
neither path nor evidence key retain compatibility; untouched original pages do
not need invented proofs.

**Closure:** IR regressions cover both masks, bytes, path substitution, missing
and invalid paths, missing and null evidence, legacy acceptance and untouched
pages. Separate public CLI tests mutate each mask, require strict QA and export
refusal, check that the previous CBZ and document bytes survive, then rebuild
mask/clean/typeset and successfully publish.

## R04 — A derived file can violate its content-addressed identity

**Impact:** the public clean command consumes an altered per-region mask under
its original SHA-256 filename and commits a result. Recomputing evidence after
consumption cannot prove that the intended mask was used.

**Repair:** add `certify::verify_content_addressed` with streaming file hashing
and invoke it from the confined CLI derived-asset reader. Recognize only a full
64-hex trailing digest. Check the logical referenced filename after canonical
workspace confinement, so an internal symlink to a differently hashed file cannot
substitute its identity. Restrict this check to derived folders (`masks`, `clean`,
`rendered`, `crops`, `sheets`); arbitrary source and external names are not proofs.

**Closure:** the CLI refuses modified region-mask bytes before document commit
and succeeds after regeneration. A Unix symlink case preserves the logical
digest check. Positive cases cover uppercase digests, unhashed legacy names and
source names with digest-like suffixes. The previous native alpha/precision QA
test now gives deliberately forged RGB files internally consistent names and
record digests, so it still independently proves that the pixel-preservation
oracle rejects them rather than stopping at the new filename guard.

## R05 — Panel geometry is absent from rendering freshness

**Impact:** changing, adding or removing page panel rectangles leaves old masks,
cleaning and lettering fresh even though panel clipping and balloon recovery use
those rectangles.

**Repair:** include normalized actual panel rectangles in the render facet in
`revayat-ir/src/stages.rs`. Use the same object-`bbox`/legacy-array projection as
the consumer; ignore unrelated panel notes. Preserve source-only detection
freshness and equivalent geometry representations.

**Closure:** changed/added/removed rectangles invalidate masks, clean and typeset
and prevent final export. Unrelated notes and equivalent forms keep the same
revision. Public CLI refusal preserves the last good CBZ and document, and the
complete regeneration path restores strict QA and export.

## R06 — Export disagrees with typed IR decisions and selected artifacts

**Impact:** explicit kept/dropped/completed-erased states and supported
`cleaned`, `rendered` and `fa_text` aliases can pass IR certification yet fail
ordinary export. Draft export may fall back to the original page after a missing
required final image while claiming no `unrendered_pages`.

**Repair:** deserialize each page through `PageRecord` and use shared
`region_state` and `required_artifact`. Retain raw structural validation and
path/source guards. Select a readable artifact with its `Artifact` identity,
and compare what is actually shipped with what the decisions require. Only
missing files permit draft fallback; unsafe paths and other errors still fail.

**Closure:** test ordinary and draft export, explicit/canonical actions, all
artifact aliases, pending erase, contradictory actions and missing final/clean
artifacts. Open the actual CBZ, assert its page bytes and package validation, and
prove refusal does not replace the document or previous output.

## R07 — DOCX duplicates the region-kind and decision contracts

**Impact:** supported kinds, including balloon/caption/title/watermark, are
rejected; a state-only kept region is labeled unresolved; conflicting actions can
produce a misleading companion. Some accepted text aliases disappear.

**Repair:** use the shared `REGION_KINDS` registry and normalize only the
decision/text subset through `RegionRecord` and `region_state`. Preserve review
snapshots without geometry, the existing companion `source`/`target` aliases,
free-form notes, nullable text/fill behavior and XML validation.

**Closure:** test every canonical kind, keep/drop state aliases, text aliases,
completed erase and translated labels, and contradiction refusal. Inspect generated DOCX XML
for the intended Persian text and outcome; preserve the previous file on error.

## R08 — CLI producers ignore accepted action states

**Impact:** `state=erased` with `erase=false` is accepted by the IR but the public
mask/clean path skips the region. A normal dark glyph remains unauthorized;
the reproduced assertion is mask0 instead of mask255. Related raw-action readers
must use the same accepted state to avoid a publication-only repair.

**Repair scope:** align editable-region selection, dropped-neighbor filtering
and watermark locked/solid-mask selection with explicit action states. Record a
successful fill for an erased balloon that was actually cleaned. Preserve locked
watermark approval, contradictory-action rejection, source immutability and the
distinction between keeping, dropping and erasing.

**Closure:** exercise the public erasure pipeline and scoped action variants,
including approved/refused watermark paths and balloon completion. A rejected
action must not partially commit an earlier page. The shared producer and export
semantics belong in this single PR.
