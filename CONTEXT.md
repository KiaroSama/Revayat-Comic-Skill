# Revayat Comic

Persian comic translation preserves the artwork while recording the meaning and
review decisions of every text region.

## Language

**Primary edition**: The translated CBZ, PDF or folder of pages whose artwork
preservation and package integrity are checked against the imported original.
_Avoid_: Review document, enhanced reading copy

**Word companion**: An editable document containing translation text and review
information, accompanying the primary edition rather than replacing its pages.
_Avoid_: Word comic, primary edition

**Region**: A stable, identified text area with its source, Persian rendering and
explicit final decision, independent of its current position or appearance.
_Avoid_: Unidentified string

**Full rendering**: The complete Persian meaning retained when a shorter displayed
variant is proposed for the page and reviewed as a pair.
_Avoid_: Summary

**Translation activity log**: The using agent's durable record of reading,
translation, correction, quality and delivery decisions beside the output.
_Avoid_: CLI diagnostics, coding-session log

**Enhanced reading copy**: A separately identified image used to inspect poor
source detail without replacing the immutable artwork preservation baseline.
_Avoid_: Restored original

**Translation batch**: A bounded set of explicitly assigned, independently workable
text groups drafted from one identified source/context/terminology snapshot.
_Avoid_: Unrestricted parallel pages

**Coordinator**: The agent responsible for accepting worker drafts and reviews,
reconciling voices and terms, and committing canonical translation decisions.
_Avoid_: Concurrent canonical writers
