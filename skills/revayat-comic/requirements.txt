# Python 3.12 or newer. NumPy 2.5+ requires Python 3.12+, and the scripts use
# modern Python typing throughout. CI tests 3.12, 3.13 and 3.14 across Linux,
# macOS and Windows, plus a Python 3.12 lane pinned to the literal minima below.

# Core — required for every run.
pillow>=10.0                  # page IO, and the Persian text renderer
numpy>=2.5.5                   # every pixel measurement
# 4.10.0.84 is the first opencv-python-headless wheel built against the NumPy 2
# ABI for Python 3.12+. Older 4.8/4.9 wheels crash at import under NumPy 2.5+.
opencv-python-headless>=4.10.0.84 # balloon detection, masks, inpainting

# Strongly recommended. Without it CBZ, CBR and folders still work, but PDF
# input and PDF export do not.
# 1.24.3, not 1.24: the scripts `import pymupdf`, and 1.24.0 through 1.24.2
# only expose the module as `fitz` — they install cleanly and then fail at the
# first PDF. The CI job that installs the literal minimum is what found it.
pymupdf>=1.24.3

# Persian shaping fallback. Pillow wheels normally ship RAQM, which does this
# properly through HarfBuzz and FriBidi; these two are only used when it does
# not, and `doctor` says which path is in effect.
arabic-reshaper>=3.1.0
python-bidi>=0.4

# The hosted adapters in scripts/adapters.py need NO package at all — they are
