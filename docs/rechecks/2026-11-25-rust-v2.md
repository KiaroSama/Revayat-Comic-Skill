## Confirmed failures and implemented repairs

### R01 — Native samples and alpha disappeared outside all edit masks

**High impact.** CLI clean/typeset converted every source to RGB8 and saved that
conversion. QA compared already-converted copies, so an empty authorization
mask still produced a false pass. In the signed Linux x64 v2.0.0 release,
RGBA processing lost alpha on 2,304 of 3,072 pixels; 16-bit grayscale lost
precision on 3,060 of 3,072 samples. All pipeline commands, including strict QA
and CBZ export, returned success.

`revayat-io/src/images/native.rs` now composites authorized RGB8 working edits
into original native samples. It supports L8/LA8/RGB8/RGBA8 and their 16-bit
variants, preserves alpha everywhere and unchanged color channels even inside
the mask, and promotes grayscale only when an authorized colored edit needs it.
Unsupported float formats and mismatched dimensions refuse explicitly. Native
QA reads exact RGBA16-normalized samples from both cleaned and rendered files;
it does not use the processing conversion as its oracle.

Proof: `native_preservation.rs` covers all eight types and low-bit/hidden-color
changes. Public CLI tests compare native output bytes and exported PNG samples,
then forge precision/alpha loss separately in clean and final artifacts to
prove that QA rejects both.

### R02 — PDF annotation preflight underestimated native resolution

**High impact.** Density inspection fitted the untransformed annotation BBox,
used a visibility mask different from Hayro, and omitted the normal `Off`
appearance fallback. A 100 x 100 image displayed in a 10 x 10 point annotation
on a 50 x 50 point page requires a 500 x 500 raster. The library produced only
50 x 50 at 72 DPI; the published CLI produced 209 x 209 at its 300-DPI default.
Both accepted an insufficient 249,999-pixel budget.

`pdf_density.rs` now fits the Matrix-transformed BBox and follows the pinned
renderer’s flag and appearance selection. Degenerate geometry refuses. Tests
cover scaled, rotated, translated and nonuniform matrices, visibility/fallback
branches, native pixel/paper preservation, and transactional budget refusal.

### R03 — Failed PDF content became an immutable blank page

**High impact.** The default interpreter warning sink discarded explicit
image decode, unsupported-font and unresolved-appearance failures. Generated
PDFs therefore imported missing or blank content successfully.

`pdf.rs` records these content-loss warning categories with a bounded atomic
bitset and refuses with a page-specific diagnostic. Prior workspace bytes are
preserved. Tests include corrupt DCT data, unusable fonts, unresolved visible
annotations and a valid standard Helvetica positive control. Both image-loss
and density defects also reproduced in the signed published executable.

### R04 — Worksheet replacement and framing disagreed with the protocol

**High impact for translation integrity.** Missing `fa`, deleted notes,
speaker and full wording could reuse previous values. Bare carriage returns
and multiline titles could turn stored text into worksheet fields or blocks.
Explicit blank paragraphs did not round-trip.

`replies.rs` and `worksheet.rs` apply whole-reply replacement semantics,
normalize physical line boundaries before escaping, preserve explicit empty
paragraphs and flatten comment headers. Missing required translations refuse
without mutating the page. Reader notes remain separate from processing audit
records. The IR recheck suite covers every deletion/framing case and existing
duplicate-field/ID protections.

### R05 — Review evidence was rejected, ignored, or trapped in a retry loop

**High impact.** `reviewed: zwnj-review` was interpreted as a boolean and never
reached falint or image QA. Compression review was unenforced. During integration,
an additional real failure showed that renewing the same bare review after a
layout change was skipped because its semantic reply digest had not changed.

`review.rs` binds approvals to region, source/revision and displayed wording;
compression also binds full wording and layout. Rebuilt `code@fingerprint`
entries carry evidence, while a bare code is an explicit current decision.
Legacy span evidence is not promoted to whole-text approval. CLI falint and
vision QA consume the verified evidence without waiving image/geometry gates.

Generated worksheets now include `# content-fingerprint:` alongside geometry
and scheme headers. Page/receipt content tokens distinguish exact retries from
fresh reapproval and stale replay. Tests prove fresh geometry/source-revision
approval succeeds, old raw replies refuse, interrupted restamping remains
recoverable, and the complete QA/export/reapproval cycle terminates successfully.

### R06 — Publication did not require current, complete QA

**High impact.** State-only keep/drop/erase changes and current `mask_bounds`
were missing from stage input identities. QA and export lacked a common
freshness/compression preflight. Even a current, hash-certified rendered page
could export while strict linguistic QA failed.

Effective actions and current mask placement now participate in the relevant
facets. `certify::certify_publication` shares artifact, file-evidence, current
clean/typeset, relevant upstream freshness and compression checks. It excludes
an old export stamp and unrelated crop history, avoiding an export-rerun
deadlock. Untouched source-only pages need no synthetic rendering stages.

The CLI calls `export_document_with_preflight` to run strict image/linguistic QA
under the export workspace claim. Failed QA occurs before destination mutation;
only explicit drafts bypass it. The compatibility library writer keeps its
artifact-level API, and applications can supply their own locked preflight.
Tests cover stale/refreshed geometry, missing/legacy proof, reviewed/unreviewed
shortening, a rejected rendered ambiguous phrase, successful reviewed export,
explicit draft behavior and a competing writer refused during preflight.

### R07 — Processed chapters could not safely enter batch mode

**High impact.** Batch inventory expected retired Python paths instead of
current flat content-addressed assets. It omitted current crop/clean/authorized
mask references and could accept a cross-page mask without copying it. The CLI
also silently ignored a different `--doc` basename and operated on comic.json.

`batch.rs` inventories current and legacy layouts with page/region ownership,
includes every referenced artifact in snapshots and publication, and retains
optimistic rollback and exact replay. The CLI refuses a noncanonical document
filename before output creation. Two-worker library tests exercise changed
assets, cross-page refusal, drift and replay; the public CLI plans and merges
an actually cleaned/typeset chapter and reruns strict QA.

### R08 — Cached contours authorized outdated geometry

**High impact.** Cached balloon text bounds/polarity could override the current
anchor, and cache reuse could ignore a current panel boundary. `masks.rs`
now treats saved bounds as a search window and revalidates the current anchor,
polarity, enclosure and panel. Two-balloon and incompatible-panel failures are
regression tests; real panel clipping and outline protection remain covered.

### R09 — Glyph identity, directional isolates and curved ink were unsound

**High impact.** Glyph proof erased word spaces, ZWNJ and ZWJ, accepting a
different joined Persian word. Typesetting removed PDI while retaining LRI,
including across wraps. Curved lettering could report a fit while clipping ink
at its canvas boundary.

`qa.rs` preserves word/join identities while normalizing only actual wrapper
transformations; `typeset.rs`/`typefit.rs` preserve logical text and balance
isolates per visual line; `lettering.rs` recenters the complete curved envelope.
Real bundled-font tests cover each failure, authored punctuation after a hard
break, leading digits, missing glyph ink, and nonempty unclipped curved output.

### R10 — Layout boundary arithmetic could panic or wrap

**Medium impact.** Oversized padding, word spacing, line strides and font caps
triggered five overflow panics. Reversed spans and excessive clearance produced
invalid success/proof results. Local checked or justified saturating arithmetic
now returns invalid/no-fit outcomes. Seven pre-fix failures and existing normal
cases pass in the layout kernel; no unchecked fallback or warning suppression
was added.

### R11 — Detection settings and reviewed-page selection were incomplete

**Medium impact.** Documented threshold/page flags were absent, gutter/SFX
controls did not drive detection, and one reviewed page aborted an entire mixed
chapter. The CLI now exposes and validates all documented ratios, `--pages`
and `--no-sfx`, preserves reviewed pages and stamps only processed pages with
their actual options. The kernel’s original strict-gutter API stays compatible.
Tests verify real panel/SFX effects, exact 29/100 threshold equality, invalid
NaN/range/cardinality inputs, selection and reviewed-page preservation.

### R12 — The mandatory activity log blocked folder publication

**Medium impact.** Journal recovery treated the public destination like private
staging and rejected its required translation log. `journal.rs` permits
untouched non-image sidecars only in the public folder. Extra page images,
foreign modifications and unowned staging/backup entries still refuse.
Promotion, rollback, late sidecars and foreign-file controls verify the boundary.

### R13 — Watermark rectangles were silently clipped

**Medium impact.** Partly off-page boxes were accepted with different dimensions.
`watermark.rs` validates the full rectangle before applying it and preserves a
valid box exactly. Tests cover partial overflow, integer overflow, exact edges
and a mixed-size two-page CLI transaction: a later invalid page leaves earlier
pages and the document unchanged.

### R14 — Adjacent panels’ dialogue was interleaved

**High impact for reading order.** Detection globally sorted region rows and
stored raw panel arrays without region membership. Worksheet moves/additions
did not refresh membership/order.

Vision now completes each panel before crossing its gutter, then orders regions
inside it in the source direction. IR normalizes legacy raw panels to stable
ID/bbox records, retains existing panel IDs, assigns at least 60% overlap to
the first matching panel and orders unassigned regions last. Worksheet geometry
changes refresh membership/order; text-only edits preserve reader order. IDs
are never reassigned. Synthetic RTL/LTR scenes, overlap boundaries, stable legacy
conversion, moved/added regions and actual detect/mask/crop CLI tests prove it.

Run these commands with the pinned Rust 1.100.0 toolchain:

```powershell
cargo fmt --all --check

cargo test --workspace --locked

```

The final integrated local run passed **254 tests, with zero failures and zero
ignored tests**, across 44 test/doc-test phases. Formatting, workspace Clippy
with `-D warnings`, and actionlint 1.7.12 also passed. The PR description records
live CI for its published head. Intermediate crate/subset counts must not be added together. Generated
fixtures exercise positive and refusal paths; source failures were observed
before their fixes. Compiler setup/disk limits were infrastructure events and
were not reported as repository test failures. Independent domain reviews and
integration reviews were performed before publication.

All 15 actual v2.0.0 release assets matched live API sizes/hashes. Four ZIPs
passed CRC/member/mode/machine-header checks; four archive signatures and the
signed SHA256SUMS verified; all five one-byte-tampered copies were rejected.
The actual Linux x64 binary passed doctor (nine kernels) and generated CBZ/PDF/
folder/RAR/DOCX, traversal-refusal and animation-refusal probes. Windows/arm64
release files were structurally verified, not locally executed; native execution
is established by the PR’s corresponding CI jobs, not inferred from ELF/PE headers.

No live paid OCR/image provider or real comic was used. Tests cannot establish
translation meaning or artistic quality for arbitrary pages; the existing
per-page human visual/linguistic review remains mandatory. No claim of universal
